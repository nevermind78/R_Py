NoteQuestion 1 : quelle est la différence entre R et RStudio ?

R est le langage et le moteur de calcul ; RStudio est l’interface (IDE) qui facilite son utilisation. On installe R d’abord, puis RStudio.

NoteQuestion 2 : pourquoi le code suivant échoue-t-il ? 
prix <- 10
Prix * 2

R est sensible à la casse : Prix (avec un P majuscule) n’existe pas, seul prix a été créé.

NoteQuestion 3 : quelle est la différence entre install.packages() et library() ?

install.packages("pkg") télécharge et installe le package une seule fois ; library(pkg) le charge dans la session courante, à faire à chaque nouvelle session.

1. Les types de données de base

Chaque valeur en R a un type (ou classe). Les quatre types de base sont :

Type Exemple class() Description
Numérique 42.5 "numeric" Nombres réels (type par défaut des nombres)
Entier 42L "integer" Nombres entiers (suffixe L)
Texte "bonjour" "character" Chaînes de caractères, entre " ou '
Logique TRUE, FALSE "logical" Booléens (T et F existent mais évitez-les)

Tester et convertir

Les fonctions is.*() testent le type ; les fonctions as.*() convertissent.

La coercition implicite

Un vecteur ne contient qu’un seul type. Si vous mélangez, R convertit vers le type le plus général, dans l’ordre : logique → numérique → texte.

AstuceAstuce

sum() et mean() sur un vecteur logique comptent et calculent la proportion de TRUE. Très pratique : mean(notes >= 10) donne le taux de réussite.

Valeurs spéciales

Valeur Signification Test
NA Valeur manquante (Not Available) is.na(x)
NULL Objet vide / absence d’objet is.null(x)
NaN Résultat mathématique indéfini (Not a Number) is.nan(x)
Inf, -Inf Infini is.infinite(x)

Attention à la précision des nombres décimaux

Les ordinateurs stockent les nombres décimaux de façon approchée. Pour comparer des nombres non entiers, utilisez all.equal().

NoteLe recyclage

Quand deux vecteurs n’ont pas la même longueur, R recycle le plus court :

1:6 + c(10, 20)     # équivaut à 1:6 + c(10, 20, 10, 20, 10, 20)

Si la longueur du plus long n’est pas un multiple du plus court (1:5 + c(10, 20)), R émet un avertissement.

3. Facteurs, matrices et listes

Les facteurs : variables qualitatives

Un facteur représente une variable catégorielle (sexe, catégorie, niveau…) avec un ensemble fini de modalités (levels).

Un facteur peut être ordonné (variable ordinale) : les comparaisons deviennent possibles.

Les matrices

Une matrice est un tableau à deux dimensions dont tous les éléments ont le même type.

Les listes

Une liste peut contenir des éléments de types et de tailles différents (même d’autres listes).

Note[ ] ou [[ ]] ?
  • liste["age"] renvoie une sous-liste (de classe list).
  • liste[["age"]] ou liste$age renvoie le contenu (ici un nombre).

Analogie : [ ] donne la boîte, [[ ]] donne ce qu’il y a dans la boîte.

7. Synthèse

ImportantÀ retenir
  • 4 types de base : numeric, integer, character, logical ; class() pour connaître le type, as.*() pour convertir.
  • Un vecteur ne contient qu’un seul type (coercition automatique).
  • NA = valeur manquante : utilisez na.rm = TRUE ou is.na().
  • Indexation avec [ ] : positions, positions négatives, conditions logiques. La numérotation commence à 1.
  • Facteur = variable catégorielle ; matrice = tableau d’un seul type ; liste = conteneur hétérogène ($ / [[ ]]) ; data frame = tableau de colonnes (df[lignes, colonnes], df$col).
  • Les opérations sont vectorisées : évitez les boucles inutiles.
  • Fonctions clés : mean, median, sd, sum, min, max, sort, table, unique, paste, ifelse, which.
