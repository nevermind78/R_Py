1. Qu’est-ce que R ?

R est à la fois un langage de programmation et un environnement logiciel dédiés à l’analyse statistique et à la visualisation de données. Il est libre, gratuit et multiplateforme (Windows, macOS, Linux).

Pourquoi R ?

  • Pensé pour la statistique : régressions, tests, séries chronologiques, etc. sont disponibles nativement.
  • Un écosystème énorme : plus de 20 000 packages sur le CRAN (le dépôt officiel), couvrant la biologie, l’économie, la finance, les sciences sociales…
  • Graphiques de qualité publication (ggplot2).
  • Reproductibilité : votre analyse est un script, que l’on peut relire, partager et rejouer.
  • Une communauté active : forums, livres gratuits, formations.
NoteR et RStudio, ce n’est pas la même chose
  • R est le moteur : c’est lui qui exécute vos calculs.
  • RStudio est le tableau de bord : un environnement de développement (IDE) qui rend R agréable à utiliser (éditeur de code, aide, graphiques, gestion de projets…).

On installe donc R d’abord, puis RStudio. RStudio ne fonctionne pas sans R.

2. Installer R et RStudio

Étape 1 : installer R

  • Windows
  • macOS
  • Linux (Ubuntu / Debian)
  1. Rendez-vous sur https://cran.r-project.org/ et cliquez sur Download R for Windows.
  2. Cliquez sur base, puis sur Download R-4.x.x for Windows (le fichier .exe).
  3. Lancez l’installeur. Choisissez la langue, acceptez les options par défaut (Suivant jusqu’à Terminer).
  4. Vérification : le menu Démarrer contient maintenant R x64 4.x.x.
NoteRtools (facultatif, plus tard)

Rtools n’est nécessaire que pour installer certains packages qui doivent être compilés depuis leur code source. Dans ce cours, ce n’est en général pas nécessaire. Si un message d’erreur vous le demande un jour : https://cran.r-project.org/bin/windows/Rtools/.

  1. Rendez-vous sur https://cran.r-project.org/ et cliquez sur Download R for macOS.
  2. Téléchargez le fichier .pkg adapté à votre Mac :
    • Apple silicon (puces M1, M2, M3…) : version arm64 ;
    • Intel : version x86_64.
    (Menu Pomme → À propos de ce Mac pour connaître votre puce.)

Dans un terminal :

sudo apt update
sudo apt install r-base r-base-dev

Pour obtenir une version plus récente que celle de la distribution, suivez les instructions du CRAN pour votre distribution : https://cran.r-project.org/bin/linux/.

Étape 2 : installer RStudio Desktop

  1. Allez sur https://posit.co/download/rstudio-desktop/.
  2. Téléchargez le programme d’installation correspondant à votre système (le site le propose automatiquement).
  3. Installez-le :
    • Windows : double-clic sur le .exe, options par défaut ;
    • macOS : ouvrez le .dmg et glissez RStudio dans le dossier Applications ;
    • Ubuntu/Debian : sudo apt install ./rstudio-*.deb depuis le dossier de téléchargement.
  4. Lancez RStudio. Il détecte automatiquement l’installation de R.

Étape 3 : vérifier l’installation

Dans RStudio, repérez le volet Console (en bas à gauche). Cliquez dedans, tapez la ligne suivante et validez avec Entrée :

R.version.string

Vous devez voir s’afficher quelque chose comme "R version 4.x.x (...)". Testez ensuite un graphique :

plot(1:10)

Un graphique doit apparaître dans le volet en bas à droite (onglet Plots).

AvertissementProblèmes fréquents
  • « R introuvable » au démarrage de RStudio : R n’est pas installé, ou a été installé après RStudio. Installez (ou réinstallez) R, puis relancez RStudio.
  • Caractères accentués illisibles : voir l’étape 4 ci-dessous (encodage UTF-8).
  • Erreur lors de install.packages() : vérifiez votre connexion Internet, puis tentez de changer de miroir CRAN (Tools → Global Options → Packages → Primary CRAN repository).
  • Windows, dossier de travail dans OneDrive ou chemin avec accents/espaces : cela peut causer des erreurs d’installation de packages ou de lecture de fichiers. Si vous rencontrez ce type de problème, placez vos projets dans un dossier simple, par exemple C:/cours_R.

Étape 4 : configurer RStudio (une seule fois)

Menu Tools → Global Options… (sur macOS : RStudio → Preferences…).

General → Basic

  • Décochez Restore .RData into workspace at startup.
  • Réglez Save workspace to .RData on exit sur Never.

Pourquoi ? Chaque session doit repartir d’un état propre, et le résultat doit dépendre de votre script, pas d’objets oubliés en mémoire. C’est la base de la reproductibilité.

Code → Saving

  • Default text encoding : UTF-8 (indispensable pour les accents).

Appearance (facultatif)

  • Choisissez un thème (par exemple Modern ou Tomorrow Night) et une taille de police confortable.

Étape 5 : créer votre premier projet

Un projet RStudio regroupe vos fichiers dans un dossier dédié et fixe automatiquement le répertoire de travail. C’est la bonne pratique dès le premier jour.

  1. Menu File → New Project… → New Directory → New Project.
  2. Directory name : cours_R ; choisissez le dossier parent avec Browse….
  3. Cliquez Create Project.
  4. Créez un script : File → New File → R Script (ou Ctrl + Shift + N) et enregistrez-le sous seance1.R.

3. Tour de l’interface RStudio

RStudio s’organise en 4 volets :

① Éditeur (Source)Vos scripts .R, documents Quarto, données à visualiser. C’est ici que vous écrivez et sauvegardez votre code.
③ Environnement / HistoriqueEnvironment : objets présents en mémoire (variables, tableaux). History : commandes déjà exécutées.
② ConsoleLà où R exécute les commandes et affiche les résultats. Invite >. Onglets Terminal, Background Jobs.
④ Fichiers / Graphiques / Packages / AideFiles, Plots, Packages, Help, Viewer.

Si l’éditeur n’apparaît pas, créez un script : File → New File → R Script.

Console ou script ?

Console Script (.R)
Usage Tester rapidement une commande Écrire l’analyse complète
Sauvegarde Non (l’historique seulement) Oui, dans un fichier
Exécution Entrée Ctrl + Entrée (ligne ou sélection)

Règle d’or : tout ce qui compte s’écrit dans un script. La console sert aux essais.

4.3 Appeler une fonction

Une fonction s’appelle avec des parenthèses et des arguments : nom_fonction(argument1, argument2).

Un argument peut être nommé (digits = 2) ou donné par position (2). Nommer les arguments rend le code plus lisible.

4.7 Packages : installer, puis charger

Un package est un ensemble de fonctions, de données et d’aide. R de base est déjà riche, mais la puissance de R vient des packages.

# 1) INSTALLER : une seule fois par ordinateur (télécharge depuis le CRAN)
install.packages("tidyverse")

# 2) CHARGER : à chaque nouvelle session R
library(tidyverse)
NoteL’analogie de l’ampoule

install.packages() = acheter l’ampoule (une seule fois). library() = allumer la lumière (à chaque fois que vous en avez besoin).

Lancez install.packages() dans RStudio, sur votre machine. Dans les pages de ce cours, les packages nécessaires sont préchargés par le site : il suffit d’appeler library().

6. Synthèse

ImportantÀ retenir
  • R est le moteur, RStudio est l’interface. Installer R puis RStudio.
  • 4 volets : Éditeur, Console, Environnement, Fichiers/Graphiques/Aide.
  • On travaille dans un script et dans un projet ; on n’enregistre pas l’espace de travail (.RData).
  • objet <- valeur crée un objet ; fonction(argument = valeur) appelle une fonction.
  • R est sensible à la casse ; les commentaires commencent par #.
  • ?fonction ouvre l’aide ; install.packages("nom") une fois, library(nom) à chaque session.
